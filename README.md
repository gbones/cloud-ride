# Cloud Ride — Offline Commute Learning
Mobile-first PWA for short Cloud/DevOps learning sessions during commuting.

## Run
```bash
npm install
npm run dev
```
Open the displayed local URL. For a production/offline build: `npm run build` then `npm run preview`.

## MVP
- Duration-based commute plan (15–90 min)
- Offline mini-lessons: Azure, Kubernetes, Terraform
- Flashcards
- Active-recall quiz
- Local progress via localStorage
- PWA/service-worker offline cache
